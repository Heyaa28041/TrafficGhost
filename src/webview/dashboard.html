  1. 1. Import HAR or Record: Capture real staging/production network traffic.

  3. 3. Start Mock Server: Run local server on http://localhost:4000.
  4. 4. Develop Unblocked: Test dynamic IDs, pagination, and error scenarios seamlessly!

Deliberately introduces 500ms – 1500ms latency to test skeletons, loaders, and race conditions.

Rate Limited (429)

Returns HTTP 429 Too Many Requests with Retry-After: 30 header.

Server Error (500)

Simulates backend crash or unhandled exception with HTTP 500 Internal Server Error.

Not Found (404)

Returns HTTP 404 Not Found for testing missing entity states.

Unauthorized (401)

Returns HTTP 401 Unauthorized for testing session expiry and login redirects.

Empty Response

Returns HTTP 200 with empty list [] or empty object {} to test empty UI states.
